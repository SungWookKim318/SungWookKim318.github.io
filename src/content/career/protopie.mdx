iOS, Android, Web에서 동작하는 Kotlin Multiplatform 런타임 기반의 고정밀 프로토타이핑 플랫폼입니다. Engine & Player 팀에서 코어 엔진과 Rust/wgpu 기반 Web 렌더러, iOS·Android·HarmonyOS Player 앱을 개발합니다.

## New Renderer — 벡터·클리핑·마스크 렌더링
{/* 제목이 너무 영역이 좁으니 조금 다듬기 */}

*2025.11 ~ 현재*

기존 DOM 방식의 Web 렌더러를 대체하는 Rust/wgpu 렌더러에서 벡터 path, 스크롤, 클리핑·마스크 기능을 개발했습니다. 도입 목표와 마일스톤을 수립하고 엔진·SDK·렌더러 간 연동도 주도했습니다.
{/* 추가로 내용을 조금 더 넣기, 전체적으로 어떻게 해야하는지 조언한거랑 아키텍쳐 어떻게 해야한다고 한거랑 */}

- Star/Polygon 도형을 기존 vector path와 tessellation 경로로 렌더링하도록 지원
- 스크롤 오프셋이 컨테이너의 자식 레이어에 적용되도록 scene graph와 render graph 처리 구현
- 둥근 모서리 sublayer clipping을 위한 stencil scope, 참조값 전파·복원, batch 분할, depth/stencil attachment와 WASM pass encoder 구현
- 기하 마스크 소스를 기존 path 렌더링 경로로 래스터화하고 중첩된 clip·mask 합성 구현
- 독립적인 SVG rasterizer 모듈 개발
- 기능별 설계 결정과 구현 범위를 문서화하고 관련 코드를 리뷰

**기술** · Rust, wgpu, WASM
